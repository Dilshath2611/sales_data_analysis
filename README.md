# Sales Data Analysis using PySpark and Databricks

## Project Overview
This project focuses on analyzing sales data using PySpark in Databricks. It involves loading, processing, transforming, and analyzing sales data to identify useful business insights.

## Tools & Technologies
- Databricks
- PySpark
- Python
- SQL
- GitHub

## Project Workflow
1. Uploaded the sales dataset to Databricks.
2. Loaded the dataset using PySpark.
3. Performed data cleaning and transformations.
4. Analyzed sales data to identify trends and patterns.
5. Created visualizations and KPIs using a Databricks notebook dashboard.

## Dashboard
The project includes 10 visualizations highlighting important sales metrics and trends.

## Project Files
- `pyspark project sales analysis.ipynb` – PySpark notebook containing the analysis.
- `screenshots/` – Dashboard screenshots.

## Key Learning Outcomes
- Working with PySpark DataFrames.
- Data cleaning and transformation.
- Performing sales analysis.
- Creating visualizations in Databricks.
